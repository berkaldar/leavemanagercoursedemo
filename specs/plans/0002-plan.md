## Risks & open questions
- **R-1 Environment (doctor):** profile fast runnable here, profile full runnable here; every `requires` prerequisite is met. `check.conf` does not change, so no residue run is needed.
- **R-2 Overlap check and save as one step (constraint G-3):** **Recommendation:** a single
  `INSERT … SELECT … WHERE NOT EXISTS (<overlapping Pending/Approved of the same Employee>)`. SQLite runs one statement under one write lock, so two simultaneous submissions can't both pass. Row count 0 → `OVERLAP`. It needs no transaction API, only `Db.execute` returning the row count. Proven by a test that runs 2 threads × 10 rounds.
- **R-3 A forged owner (AC-10):** the body schema has no owner field and uses `extra="forbid"` (the existing convention), so a body that names `employee_id` is refused with 422 and nothing is stored for anyone. The owner always comes from the session. **Recommendation:** keep `forbid`. The criterion holds: no request is ever stored for someone other than the logged-in person. The test sends a forged `employee_id`, checks that nothing is stored for Elif, and checks that a normal body is stored for the actor.
- **R-4 Where the refusal sentences live:** **Recommendation:** `app.http` maps each `ErrorCode` to the spec's exact sentence in the 409 `message`, and the UI shows `message` as it is. A 422 has no domain code, so the UI shows the spec's missing-input sentence. That keeps one source for the five rule sentences, which the API tests assert.
- **R-5 Clock for "server's local date":** ruff `DTZ` forbids `date.today()`. **Recommendation:** `datetime.now(UTC).astimezone().date()` inside the single `today()` dependency in `app/http`. `app.leave` gets `today` as a parameter (architecture rule 5 is unchanged).
- **R-6 Length stored or derived:** **Recommendation:** derived when the list is read (`working_days` from the dates + shutdowns). Nothing new is stored, which matches "derived, never stored" in the domain. The cost is one small shutdowns query per list.
- **R-7 Submitting and error states in J-2:** **Recommendation:** use Playwright `page.route` to hold back or abort `POST /api/my/requests` once, the same technique as J-1, with no sleeps.
