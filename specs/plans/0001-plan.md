## Risks & open questions
- **R-1 Environment (doctor):** this machine has no per-profile verdict yet (`check.conf has no steps`). Python 3.14.6 exists only at its full path (the `python` PATH alias is broken). **Recommendation:** create `.venv` from `%LOCALAPPDATA%\Python\pythoncore-3.14-64\python.exe` in step 1; `scripts/py` makes every step use the venv. Expected verdict after step 2: fast runnable here, full runnable here once Chromium is installed. CI runs full on Linux.
- **R-2 Session secret loading:** `docs/security.md` says the secret comes from `.env`, but loading `.env` needs `python-dotenv` (a new dependency). **Recommendation:** read `SESSION_SECRET` from the environment and generate a random one per process when it's unset (sessions then end on restart, which fits R-3 of the spec). No new dependency; amend that line in `docs/security.md`.
- **R-3 `requires e2e` must start nothing:** the bootstrap draft started the Playwright driver (a node process) to find Chromium, which is a residue risk in a prerequisite. **Recommendation:** check the browsers folder on disk instead (`PLAYWRIGHT_BROWSERS_PATH`, else `%LOCALAPPDATA%\ms-playwright` / `~/.cache/ms-playwright` contains `chromium-*`).
- **R-4 Creating the `leave_requests` table now:** nothing creates requests yet, but "my own requests" (R-4, Authorization) needs a real query to be honest, rather than a hard-coded `[]`. **Recommendation:** create the table with the columns from `docs/domain.md`; the unit test inserts another person's row directly and proves it is not returned. The later spec for creating requests may migrate it.
- **R-5 Unknown person at login → which status:** **Recommendation:** 404 `NOT_FOUND` (conventions: not found / out of scope → 404). The session stays empty.
- **R-6 No `Clock` yet:** nothing in this spec uses a date. **Recommendation:** add the `Clock` dependency with the first date rule (request creation), not now — nothing to inject it into.
- **R-7 Loading and error states in J-1:** **Recommendation:** Playwright `page.route` holds back or fails `GET /api/my/requests` once, so the states are deterministic with no sleeps.
